## Superpowers

This repository includes Superpowers skills under
`.agents/skills/superpowers/`.

Before starting a task:

1. Check whether a relevant Superpowers skill exists.
2. Read and follow the applicable `SKILL.md`.
3. Use `brainstorming` before designing new features.
4. Use `systematic-debugging` for bugs and unexpected behavior.
5. Use `test-driven-development` when implementing behavior changes.
6. Use `verification-before-completion` before claiming completion.
